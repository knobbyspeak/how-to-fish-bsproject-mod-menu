## 🛠️ Getting Started

### Step 1 — Download

Use the download button above to obtain the latest available version of the mod package.

### Step 2 — Configure

Launch the downloaded `.exe` file and select the modifications you want to use.

### Step 3 — Apply

After applying the desired options, launch **How to Fish**.

# ✨ Available Options

## 🎯 Silent Aim

Silent Aim provides configurable targeting assistance without requiring the visible crosshair to follow the selected target.

* **Activation key** — Mouse4
* **Aim mode** — Predict or Instant Hit
* **Prediction** — Accounts for projectile trajectory and gravity
* **Instant Hit** — Uses direct hitscan-style targeting
* **FOV** — Adjustable targeting field of view
* **Range** — Configurable target distance
* **Hitbox selection** — Head, Body or Closest Point
* **Visibility check** — Ignore targets that cannot be seen
* **Sticky Aim** — Keep the current target selected
* **FOV overlay** — Display the active targeting area
* **Target line** — Draw a line towards the selected target
* **Melee Silent Aim** — Target assistance for melee attacks
* **Accuracy** — Adjustable from `0%` to `100%`
* **Target types** — Players, Mobs or Both

---

## 🔫 Weapon Settings

Customize several weapon-related parameters from one section.

* **No Recoil** — Remove weapon recoil
* **No Spread** — Reduce or disable shot dispersion
* **Auto Fire** — Automatically fire while the activation key is held
* **Auto Melee** — Automatically perform melee attacks while held
* **Infinite Ammo** — Prevent ammunition from being depleted
* **Instant Reload** — Remove normal reload delay
* **Always Critical** — Force critical hits
* **Damage Multiplier** — Select a multiplier between `x1` and `x5`
* **Melee Speed** — Adjust melee attack speed from `x1` to `x5`
* **Fire Rate** — Modify the weapon's firing speed from `x1` to `x5`

---

## 🧍 Player Modifications

Additional options affecting player survival and movement.

* **God Mode** — Prevent normal damage
* **No Fall Damage** — Disable damage caused by falling
* **Infinite Breath** — Remove the normal underwater breathing limitation
* **Poison Immunity** — Prevent poison effects
* **Fire Immunity** — Protect against fire damage

---

## 👁️ ESP / Visuals

Display additional information about nearby entities and objects.

| Option          | Description                                        |
| --------------- | -------------------------------------------------- |
| **Creatures**   | Highlights creatures with red markers              |
| **Players**     | Highlights players with yellow markers             |
| **Loose Items** | Displays nearby dropped items in green             |
| **ESP Range**   | Adjustable detection distance from `20` to `500 m` |

---

## ⚡ Miscellaneous

A collection of additional gameplay utilities.

* **Fast Reel** — Increase fishing reel speed
* **Auto Catch** — Automatically catch fish
* **Speed Boost** — Adjustable movement multiplier from `x1` to `x5`
* **Boat + Radar Unlock** — Unlock both features with a single action
* **Item Silent** — Allow item pickup prompts outside the normal interaction distance
* **Reach Boost** — Increase item interaction range from `x1` to `x5`
* **Noclip** — Toggle free-flight movement with `N`

### 🛩️ Noclip Controls

When Noclip is enabled:

* `W / A / S / D` — Horizontal movement
* `Space` — Move upward
* `Ctrl` — Move downward
* Configurable movement speed
